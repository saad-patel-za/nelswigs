# Nel’s Wigs design preview

Responsive HTML storefront mockup for conversion to custom Shopify sections in Dawn or Horizon.

Serve this folder with any static HTTP server or GitHub Pages. No build step or dependencies are required.

Includes a responsive slideshow, mega menu, mobile navigation, collection search, product cards, Quick Look, Quick Add, preview bag, and model-photo style studio.

Product data, prices, ratings, and stock are snapshots from October 25, 2026. The preview bag exists in browser memory and resets on reload. Continuing to the store opens the selected variants on the live store, which confirms prices and availability. This mockup does not process payments.

During Shopify conversion, replace snapshot data with Liquid product objects, connect native cart and search functionality, use live review badges, and expose content as editable section settings and blocks. The studio displays original model photos, not a face-upload try-on.
